CSV 格式说明:
支持两种格式 — 简化格式 (推荐) 和 完整格式。

简化格式: url,name,auth_type
https://example.com,主站,none
http://192.168.1.1:8080,内网服务,basic
https://test.com,,cookie

完整格式: name,url,auth_type,cookie,username,password
主站,https://example.com,none,,,
后台,http://admin.test.com,basic,,admin,123456
测试,https://api.test.com,cookie,session=abc;token=xyz,,

字段说明:
• url — 目标地址 (必填, 支持 http(s):// 或 IP:端口)
• name — 目标名称/备注 (可选)
• auth_type — 认证方式: none / cookie / basic (可选, 默认 none)
• cookie — Cookie 字符串 (auth_type=cookie 时填写)
• username — 用户名 (auth_type=basic 时填写)
• password — 密码 (auth_type=basic 时填写)

注: 第一行若为表头 (包含 url/name 等字样) 将自动跳过
