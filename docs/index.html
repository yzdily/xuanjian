XuanJian（玄鉴，项目代号 xuanjian） 是一个 agentic 自动化渗透测试框架。 它驱动浏览器爬取、拦截并改写流量，按阶段方法论（爬虫 → 分析 → 并行编排测试 → 三态闭包验证 → 报告）自主执行红队任务， 并对每一个发现独立验证、抑制误报——像一个不会漏掉任何测试步骤的人类渗透测试专家。

什么是 xuanjian？

XuanJian（读作「玄鉴」，仓库代号 xuanjian）把传统扫描器、AI 辅助分析与人类渗透测试员的经验编码进同一套可执行的智能体。

它不是签名扫描器

xuanjian 像人一样工作：驱动浏览器、拦截并改写流量、推理业务逻辑、构造 payload、验证漏洞、抑制误报——但永远不会忘记某一步测试。

每个发现都可归因

每个漏洞都归属到具体的 (endpoint × 漏洞域) 对，并在稀疏覆盖矩阵上追踪状态，确保不漏测、每个端点都有结论。

自主验证，而非报告即信

独立的 LLM 审计员核验真实危害，检测层硬规则在检测当下就拦截误报，即使不开危害验证的 FAST 模式也保持干净。

可生长的技能库

把你的渗透测试经验编码为 SKILL 方法论，xuanjian 会随你一起成长；内置 discovery / exploit 技能库均为 MIT 许可。

法律声明：xuanjian 仅用于合法授权的安全测试。使用前必须获得目标系统所有者的明确书面授权，并遵守所有适用法律法规。未授权使用属犯罪行为。详见 DISCLAIMER.md。

核心能力

xuanjian 覆盖从单 URL 到凭据登录、从批处理到实时的端到端渗透测试。

能力说明
URL 端到端渗透输入目标 URL —— 爬虫 → 分析 → 测试 → 报告，全自动。
凭据式渗透输入用户名/密码 + URL，自动登录后测试。
凭据注入输入 Cookie / JWT / Header，绕过登录直接测试。
手动登录捕获Playwright 有头模式，交互捕获 Cookie/Token/Authorization，支持验证码。
SPA 智能降级自动识别 Vue / React / Angular，链接不足时切换手动浏览 + 流量录制。
验证码 OCR内置图片验证码 OCR，复杂验证码支持人工介入。
自定义 SKILL把你的渗透测试经验编码为方法论，xuanjian 持续成长。

两种正交的扫描维度

xuanjian 的「扫描模式」由两个正交维度决定，避免语义混淆。

维度一 · 扫描深度

FAST 无 LLM STANDARD 轻量 DEEP 全链路 SMART 自适应

维度二 · 编排方式

Batch 整站 Realtime 边点边测 Packet 单包全检

八阶段方法论（无人在环）

xuanjian 的流水线由真实的 core.* 模块驱动，每个阶段都可独立验证。

0

站点探索

爬虫 + JS 分析 + 流量捕获 + SPA 降级（AutoCrawler）。

1

功能分析

识别功能 → 生成测试清单（Main Agent + AnalyzeWorker）。

1.5

业务理解

语义分析 → 攻击假设（analyze_business）。

2

并行漏洞测试

HTTP 子智能体 + 浏览器项并行执行（Orchestrator）。

2.5

业务对账

清单 × 业务理解交叉验证（reconcile_loop）。

2.55

补测

对新发现的 API 自动补测（SupplementalTestAgent）。

2.6

危害验证

三态闭包裁决 + 误报抑制（HarmValidator / verdict）。

3

报告聚合

覆盖矩阵 + 漏洞详情 + 修复建议 + PoC（Main Agent）。

下一代编排引擎 core/testflow/（opt-in，环境变量 XUANJIAN_TESTFLOW_V2）围绕 8 大风险域（authz / csrf / upload / ssrf / injection / file / business / config）与稀疏覆盖矩阵、七道门控（G0–G6）进一步 deterministic 化测试。

漏洞覆盖

浏览器驱动 + 流量拦截 + LLM 深度分析，自动发现并验证：

Web 注入

SQL 注入（内置 Fuzz 引擎）、XSS（反射/存储/DOM，13 步专用引擎）。

认证授权

IDOR、认证绕过、越权访问。

服务端

SSRF（含 OOB 带外验证 + 危害证明）、信息泄露、条件竞争。

业务逻辑

验证码绕过、用户枚举、业务逻辑分析。

其他

CSRF、XXE、SSTI、文件上传、路径遍历、命令注入。

亮点

危害验证达 SRC 标准；自动生成可运行 PoC；可插拔自定义 SKILL。

误报防护（FP 铁律）

xuanjian 借鉴 api-pentest-extension 的 FP 判定铁律，由检测层（而非事后 LLM 仲裁）强制执行确定性过滤：

层级机制覆盖
业务错误码解析HTTP 200 但 code:500/未登录 → 不报越权越权 / CORS / 信息泄露
空数据检测200 但 data:null/[] → 不报数据泄露越权 / CORS
WAF 拦截页识别403/418/429 + 拦截关键词 → 跳过路径遍历 / 命令注入 / SSRF
SQL 布尔盲注 3 层校验True≈基线 且 False=WAF/报错 → 跳过SQL 注入
时间盲注二次复现延迟 ≥3.5s 且可复现，单次命中视为抖动SQL 注入
XSS 可执行上下文落在 HTML 注释/纯 JSON → 降级为弱证据XSS
证据质量分级所有发现标记 body_confirmed/header_only全部

快速开始

要求：Python ≥ 3.10、Git、约 500MB 空间（Playwright Chromium）。

方式一 · 一行命令

# macOS / Linux
git clone https://github.com/yzdily/xuanjian.git
cd xuanjian
./start.sh

# Windows (PowerShell)
git clone https://github.com/yzdily/xuanjian.git
cd xuanjian
.\start.ps1

方式二 · 手动步骤

git clone https://github.com/yzdily/xuanjian.git
cd xuanjian
python -m pip install -r requirements.txt
python -m playwright install chromium
cp .env.example .env        # 编辑 .env 填入你的 LLM API Key
python start.py             # 打开 http://localhost:7788

方式三 · Docker

git clone https://github.com/yzdily/xuanjian.git
cd xuanjian
docker compose up -d        # 访问 http://localhost:7788
启动后首次运行会在 Settings → Models 提示添加 LLM API Key；容器以非 root 运行、丢弃全部能力、仅绑定 127.0.0.1。
