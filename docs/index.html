XuanJian（玄鉴，项目代号 xuanjian） 是一个 agentic 自动化渗透测试框架。它驱动浏览器爬取、拦截并改写流量，按阶段方法论（爬虫 → 分析 → 并行编排测试 → 三态闭包验证 → 报告）自主执行红队任务，并对每一个发现独立验证、抑制误报——像一个不会漏掉任何测试步骤的人类渗透测试专家。 XuanJian (玄鉴, codename xuanjian) is an agentic automated penetration-testing framework. It drives a browser to crawl, intercepts and rewrites traffic, and autonomously runs red-team operations following a staged methodology (crawl → analyze → parallel orchestration → three-state closure verification → report). Every finding is independently verified and de-noised — like a human pentester who never skips a step.

什么是 xuanjian？What is xuanjian?

XuanJian（读作「玄鉴」，仓库代号 xuanjian）把传统扫描器、AI 辅助分析与人类渗透测试员的经验编码进同一套可执行的智能体。XuanJian (pronounced "Xuán Jiàn", repo codename xuanjian) encodes traditional scanners, AI-assisted analysis, and human pentester expertise into one executable agent.

它不是签名扫描器Not a signature scanner

xuanjian 像人一样工作：驱动浏览器、拦截并改写流量、推理业务逻辑、构造 payload、验证漏洞、抑制误报——但永远不会忘记某一步测试。xuanjian works like a human: drives a browser, intercepts and rewrites traffic, reasons about business logic, crafts payloads, verifies vulnerabilities and suppresses false positives — yet never forgets a single test step.

每个发现都可归因Every finding is attributable

每个漏洞都归属到具体的 (endpoint × 漏洞域) 对，并在稀疏覆盖矩阵上追踪状态，确保不漏测、每个端点都有结论。Every vulnerability maps to a concrete (endpoint × vuln-domain) pair and is tracked on a sparse coverage matrix — guaranteeing no endpoint is left untested.

自主验证，而非报告即信Self-verifying, not report-and-trust

独立的 LLM 审计员核验真实危害，检测层硬规则在检测当下就拦截误报，即使不开危害验证的 FAST 模式也保持干净。An independent LLM auditor validates real impact, while detection-layer hard rules block false positives at detection time — staying clean even in FAST mode without harm validation.

可生长的技能库A growable skill library

把你的渗透测试经验编码为 SKILL 方法论，xuanjian 会随你一起成长；内置 discovery / exploit 技能库均为 MIT 许可。Encode your pentest experience as SKILL methodologies and xuanjian grows with you; the built-in discovery / exploit skill libraries are MIT-licensed.

快速开始Quick Start

要求：Python ≥ 3.10、Git、约 500MB 空间（Playwright Chromium）。Requirements: Python ≥ 3.10, Git, ~500MB disk (Playwright Chromium).

方式一 · 一行命令Method 1 · One-liner

# macOS / Linux
git clone https://github.com/yzdily/xuanjian.git
cd xuanjian
./start.sh

# Windows (PowerShell)
git clone https://github.com/yzdily/xuanjian.git
cd xuanjian
.\start.ps1

方式二 · 手动步骤Method 2 · Manual steps

git clone https://github.com/yzdily/xuanjian.git
cd xuanjian
python -m pip install -r requirements.txt
python -m playwright install chromium
cp .env.example .env        # edit .env with your LLM API Key
python start.py             # open http://localhost:7788

方式三 · DockerMethod 3 · Docker

git clone https://github.com/yzdily/xuanjian.git
cd xuanjian
docker compose up -d        # visit http://localhost:7788
启动后首次运行会在 Settings → Models 提示添加 LLM API Key；容器以非 root 运行、丢弃全部能力、仅绑定 127.0.0.1。On first run you'll be prompted to add an LLM API Key under Settings → Models; the container runs as non-root, drops all capabilities, and binds only to 127.0.0.1.
