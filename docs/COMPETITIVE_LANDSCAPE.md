## 2. 重点竞品画像（A 层直接竞品）

### 2.1 XBOW（国际标杆，最像玄鉴的对手）
- **定位**：全自主 AI 渗透平台，Web/API 为主；"证据优于概率"（每个发现附可复现利用 PoC，证不出就不报）。
- **硬实力**：2025 登顶 HackerOne 美区+全球榜首（首个自主系统超越人类）；累计发现 14,000+ 零日（厂商数据）；150+ 安全团队使用；多智能体协调器 + 独立验证器。
- **商业**：融资 $75M B 轮（累计 $117M）；定价 $4,000（轻量）/$8,000（复杂）每测；合规 SOC2/ISO27001/PCI/NIS2。
- **对玄鉴**：XBOW 无中文、无等保、纯 Web/API、闭源托管。**玄鉴可切的口子**：中文 SRC 工作流、前端加密突破（CryptoHook）、等保合规模块、可自托管控成本。

### 2.2 Horizon3 NodeZero（基础设施自主渗透之王）
- **定位**：网络/AD/云为主的全自主渗透，非破坏性确定性逻辑（310,000+ 生产测试零中断，厂商数据）；2026-07-29 才扩展 WebApp 层。
- **商业**：估值 $2B（14 个月翻 3 倍，Series E）；年合同制。
- **对玄鉴**：NodeZero 强在基础设施/身份链，弱在 Web 业务/前端加密；玄鉴反之。**互补多于直接竞争**，可定位"应用层业务渗透"差异化。

### 2.3 绿盟 AI-PTS / 绿盟 AI 智能化渗透系统（国内标杆）
- **定位**：风云卫+DeepSeek 双底座、多智能体+RAG、端到端真实网络渗透；"直接模式+深度模式"双轨、人在环路。
- **落地**：获 IT168 2025 技术卓越奖；已在电信/金融/政府落地；降噪率 95%+、研判准确率 90%+（厂商数据）。
- **对玄鉴**：绿盟是上市公司，渠道/资质/政企关系碾压；但**闭源、贵、不可自托管**。玄鉴的杠杆是开源灵活、可自托管、成本可控、SKILL 社区可共创。

### 2.4 墨云科技（AI 红客团队 / Vackbot）
- **定位**：全球首个 AI 渗透智能体（5 智能体：策划师/工程师/情报分析师/探测师/脚本编辑师）；Vackbot 走 BAS 入侵模拟路线；Avdbot 做 Fuzzing 挖洞。
- **商业**：B+ 轮亿元；300+ 行业用户（人行、银联、三大运营商、电网）。
- **对玄鉴**：墨云以 BAS"攻击模拟验证"切入，玄鉴以"真实利用+检测层去误报"切入；墨云有标杆客户壁垒，玄鉴有开源社区飞轮。

### 2.5 谋乐 BUGBANK Elliot（AI 红队 + 赏金生态）
- **定位**：哥德尔机可自进化智能体；"战略脑+执行脑"双脑协同；AttackGraph 事实底座；SafeGate 沙箱；多 Gate 证据链防幻觉。
- **对玄鉴**：思路高度同源（业务理解 + 证据链 + 沙箱安全）；谋乐有 BUGBANK 赏金平台生态可转化，玄鉴需自建/借力社区。

### 2.6 Escape（API/业务逻辑专项）
- **定位**：API/GraphQL/业务逻defect（BOLA/IDOR/认证绕过）原生支持；DAST+AI；CI/CD 深度集成；代码级修复建议。
- **对玄鉴**：Escape 是"扫描器+AI"，玄鉴有浏览器交互 + SPA 降级 + 前端加密突破，对现代 SPA 更友好。

### 2.7 PentestGPT（最近的直接开源竞品）
- **定位**：USENIX Security 2024 学术出身，MIT 开源；可跑本地 LLM（敏感目标不出网）；XBOW 基准 86.5% 成功率、平均 $1.11/成功测试；完全自主端到端约 31%、人工辅助 64%。
- **对玄鉴**：这是玄鉴在"开源 AI pentest agent"赛道**最直接的同类**。玄鉴必须强化的点：**社区易用性、方法论库（SKILL）、工程化报告、去误报确定性**——否则会被 PentestGPT 类项目吸走开源用户。

## 4. 玄鉴的定位与破局建议

### 4.1 真实机会（空白带）
- **大厂闭源**（绿盟/墨云/谋乐）：有渠道资质，但贵、不可自托管、黑盒。
- **国际 SaaS**（XBOW/NodeZero/Escape）：强但无中文、无等保、数据出境敏感、按次/年合同贵。
- **纯开源**（PentestGPT/X-Ray）：免费但工程化弱、无报告、无合规、难落地企业。
- **→ 玄鉴空白位**：**面向中文政企与白帽的、可自托管、去误报可信、带等保合规模块的 AI 渗透智能体**，介于"大厂高价闭源"与"纯开源玩具"之间。

### 4.2 差异化护城河（必须守住并放大）
1. **双引擎去误报**：检测层硬规则 + 独立审核员（开源对手 PentestGPT 没有）。
2. **前端加密突破 + 浏览器/SPA 降级**：对国内大量 Vue/React + 加密表单的政务/金融系统极实用，国际对手普遍不覆盖。
3. **等保合规模块**：直连国内合规刚需，是进场政企的门票。
4. **可自托管 + MIT + SKILL 社区**：成本可控、数据不出网、方法论可共创——对抗大厂闭源的核心杠杆。
5. **赏金/经验飞轮**：借鉴谋乐 BUGBANK，把扫描经验沉淀成可复用 SKILL 市场。

### 4.3 主要威胁
- 绿盟/墨云/谋乐用**资本 + 渠道 + 资质**碾压中小客户。
- XBOW 若本地化入华（中文+合规）将正面冲击高端。
- 开源同类（PentestGPT/HexStrike）吸走社区注意力 → 玄鉴须"社区体验 + 方法论库"双优。

## 6. 给产品路线的启示（接 `PRODUCT_STRATEGY_AND_ROADMAP.md`）

1. **社区即护城河**：PentestGPT 已证明"开源 AI pentest agent"有真实需求，玄鉴必须在"社区易用性 + SKILL 方法论库 + 去误报确定性"上做到开源阵营第一。
2. **合规是入场券**：等保/合规模块必须进企业版核心，而非点缀。
3. **前端加密突破是独门**：重点打磨 CryptoHook + SPA 降级，作为对国内系统的"降维打击"卖点。
4. **对标 XBOW 的"证据优于概率"**：玄鉴的"检测层铁律 + 独立审核员"已是同构能力，对外话术可直接对标，强化"可信报告"心智。
